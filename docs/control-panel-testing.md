# 中控台本地验收清单

当前状态（2026-09-16）：用户反馈本地总体测试无问题，并已明确授权移除旧 slash。代码中的命令清单现仅保留 `/control`、`/manual`、`/ping`、`/refresh`。以下过渡期旧入口检查作为历史验收步骤保留；后续复测应确认旧命令消失、原消息控件仍可用，不再要求旧 slash 可执行。

本清单用于 Discord 实际联调。方框默认未通过，请在本地验证后勾选。自动测试已覆盖部分逻辑，但不能代替客户端、权限、网络和重启验证。

## 1. 准备测试环境

- [ ] 备份当前 `storage/` 数据和图片；确认测试 bot、应用 ID、服务器 ID 匹配。
- [ ] 准备管理员和普通成员两个账号，以及中控台、Reminder、报名/投票、分队、公告、市场队列和通知频道；可按需要复用频道。
- [ ] 执行 `npm ci` 和 `npm test`，记录结果。
- [ ] 在确认 `.env` 指向测试环境后执行 `node deploy-commands.js`。该操作会同步并替换目标服务器的应用命令列表。
- [ ] 执行 `node index.js`，确认启动成功。已有配置会恢复看板和调度任务。
- [ ] 确认 `/control`、`/refresh`、`/manual` 及过渡期旧命令均可使用。

## 2. 中控台与帮助

- [ ] 管理员用 `/control set-channel` 建立入口，显示 Reminder、活动报名、公告、投票、Market、帮助六个模块。
- [ ] 双账号同时打开不同模块，私密操作互不干扰，公开中控台不被替换。
- [ ] Help 无多层菜单，能指引报名、公告、投票、提醒、市场及 `/manual section:quick`。
- [ ] 普通成员使用各 `/manual section:...` 都收到私密说明；不带 section 时提示使用私密入口。管理员不带 section 时公开发送快速上手。
- [ ] 同频道重复设置只更新面板；删除后重新设置可恢复。换频道后新面板有效、旧面板删除。
- [ ] 无法发布到新频道时保留旧设置；旧消息无法删除时，新面板仍有效并私密提供旧链接。

## 3. 各模块基本操作

| 模块 | 操作与预期 | 通过 |
| --- | --- | --- |
| Reminder | 管理员从模块设置主频道，在看板增删改提醒及通知设置；普通成员只可刷新/同步日夜。验证实际触发时间和通知频道。 | [ ] |
| 活动报名 | 普通成员创建普通/职业报名，另一账号参与及取消；职业与继承/觉醒选择正确；创建者可结束，其他普通成员不可结束。 | [ ] |
| 分队 | 管理员设置频道、建队、分配成员、刷新、发布与关闭。改默认频道不移动已有面板，删除后重建使用新频道。 | [ ] |
| 投票 | 普通成员创建、投票和改票；仅管理员能提前结束。测试自动到期、无人投票和临近到期手动结束，原频道仅出现一次结果。 | [ ] |
| 公告 | 管理员建立模板与别名，选频道、偏移与发送方式，核对预览后发送。检查未过期限制、强制重发、无时间戳和旧消息删除失败提示。 | [ ] |
| 公告图片 | 弹窗上传图片，编辑文字后图片仍在；替换/移除图片、删除模板清理文件，已经发送的公告不变。拒绝不支持格式或超过 8 MiB 的新图片。 | [ ] |
| 市场队列 | 配置队列频道；从其他频道 `/refresh` 仍更新配置频道，连续调用有冷却，自动刷新时间不变。 | [ ] |
| 上架提醒 | 关键词搜索、翻页选物品、选强化或不限、确认关注；检查实际匹配通知；移除列表只含本人记录，打开列表不会删除。 | [ ] |

## 4. 停止、异常与重复操作

- [ ] 市场更新进行中停止追踪，完成停止后不再发布后续结果；已有队列消息标记停止/旧数据。新请求与上架提醒暂停，配置和关注记录保留。
- [ ] 停止期间 `/refresh` 不获取数据，改频道也不恢复；管理员恢复后使用保存配置并立即刷新。一个服务器停止不影响其他活跃服务器。
- [ ] 模板/别名列表超过 25 项、物品搜索超过 25 项时可翻页；空列表给出可理解的提示。
- [ ] 预览后修改公告模板或别名，确认时出现更新后的预览，重新确认后才发送。
- [ ] 连续点击确认或重复提交不会重复创建公告、投票、报名或分队面板。
- [ ] 发布到无权限/已删除频道、选择已删除角色、模板图片缺失时有私密反馈，不误报成功。
- [ ] 管理员在流程中失去权限后不能提交受限操作；普通成员不能使用管理入口或操作他人流程。
- [ ] 等待私密流程超过 15 分钟后提交，提示重新打开；重新打开后可正常操作。

## 5. 重启与兼容性

- [ ] 重启后中控台和 Reminder 恢复且不重复，原有报名/分队控件仍工作。
- [ ] 活跃旧投票可继续投票；离线期间到期的投票上线后结算。结果已保存的投票重试时不重复公布。
- [ ] 市场停止状态跨重启保留；已有关注、频道设置、公告模板/别名和绑定图片仍在。
- [ ] 重启前未完成的私密流程失效，重新打开可继续操作。
- [ ] 抽查保留的公告、报名、投票、市场、Reminder slash 入口，行为与新面板的共用逻辑一致。
