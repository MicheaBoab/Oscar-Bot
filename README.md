# Oscar-Bot

基于 discord.js v14 的 Discord 机器人，提供活动报名与分队、投票、公告、定时提醒、黑沙市场队列和上架提醒。

## 快速上手

1. 管理员执行 `/control set-channel channel:#中控台`，建立固定入口。
2. 点击模块，打开仅自己可见的操作面板。创建的公告、报名和投票发布到所选频道。
3. 任何成员使用 `/manual section:quick` 私密查看手册；指定其他 section 查看模块说明。管理员使用不带参数的 `/manual` 会公开发送快速上手。

私密流程有效期为 15 分钟，机器人重启后需重新打开。发布目标必须是当前服务器的文字频道，成员和机器人都需要相应发送权限。机器人发布嵌入内容需要嵌入链接权限，公告图片需要附件权限，提及不可公开提及的角色需要相应提及权限。

## 模块操作

| 模块 | 从中控台开始 | 权限 |
| --- | --- | --- |
| Reminder | 查看或设置主频道；日常操作在该频道看板上 | 刷新/同步日夜所有成员可用；设置与提醒管理仅管理员 |
| 活动报名 | 普通/职业报名 → 频道 → 标题与说明 | 所有成员可创建/参加；创建者或管理员可结束；分队等管理仅管理员 |
| 公告 | 频道 → 模板 → 身分组别名 → 发送方式与偏移 → 预览确认 | 全部操作仅管理员 |
| 投票 | 创建 → 频道 → 标题、每行一个选项、时长 | 所有成员可创建/投票；仅管理员可提前结束 |
| Market | 市场队列 / 上架提醒 | 设置、停止/恢复仅管理员；成员管理自己的关注 |
| 帮助 | 私密显示模块指引及手册入口 | 所有成员 |

### Reminder

管理员从 Reminder 模块设置主频道，之后在公开看板的管理员菜单新增、编辑、删除提醒，以及配置通知频道和提及身分组。所有成员可刷新看板、同步日夜。

- 频率示例：`每周日`、`每两周周一`、`每2周周五`。
- 提醒时间：24 小时制 `HH:MM TZ`，例如 `20:30 CDT`、`08:20 PT`、`22:00 ET`。
- 可选活动范围：`MM.DD.YYYY-MM.DD.YYYY [TZ]`，例如 `08.01.2026-10.31.2026 CDT`。省略时区时继承提醒时间的时区。
- 无效时间、时区或日期范围会返回具体提示。保存提醒后自动刷新看板。

中控台与 Reminder 更换频道时，先发布新面板并保存位置，再删除旧面板。旧消息删除失败会私密提供链接，由管理员手动删除。同频道设置会更新已有面板。

### 活动报名与分队

创建时选择普通报名或职业报名，再填写标题（最多 180 字符）和说明（最多 3000 字符）。成员在活动消息上通过按钮或职业菜单参与；职业报名还可选择继承/觉醒。重名或存储文件名冲突时需要更换标题。

创建者或管理员可结束报名；其他管理操作仅管理员可用。管理员在模块中设置默认分队频道，再从活动消息进入分队管理，建立队伍、分配成员、刷新、发布或关闭面板。改变默认频道不移动已有分队面板，新建或删除后重建时使用新设置。

中控台不提供跨频道活动列表、独立参与者列表或公开通知全体报名者入口。

### 公告与图片

管理员先在公告模块建立模板和身分组别名（每个别名 1–5 个身分组），再进入发送流程。同名身分组别名会更新为本次选择。模板和别名列表支持翻页。

- 模板最多 4000 字符；实际正文与提及合计最多 2000 字符。
- 可选偏移：`+10m`、`-30s`、`+2h`、`-1d`；留空无偏移。偏移只作用于本次发送，不修改模板。Discord 时间戳沿用周期时间计算规则。
- 模板图片通过弹窗上传，单张最多 8 MiB，支持 PNG/JPEG/GIF/WebP 文件签名检查。
- 图片保存为 `storage/notice-images/notice_<安全别名>_<uuid>.<扩展名>`，持续绑定到模板。编辑文字保留图片，重启后仍可使用。
- 替换图片先保存新绑定，再清理旧文件；也可单独移除图片。删除模板会清理其不再被引用的图片。已发出的公告不随模板修改而改变。
- 预览展示正文、图片、频道、提及角色和旧公告删除提示；确认前发现内容改变时，需要再次确认。
- 同一模板与身分组别名的上一条公告尚未过期时，需要选择强制重发。无时间戳的公告可再次发送。
- 新公告发送并保存记录后才尝试删除上一条；删除失败会私密提供手动处理链接。若提示记录保存失败，请先检查已发送的消息，不要直接重复发送。

模板与身分组别名沿用现有共享文件，尚未改成各服务器独立存储；旧 `storage/images/` 图片路径仍兼容。

### 投票

选项每行一项，共 2–25 项，每项最多 100 字符；标题最多 180 字符。时长支持 `30s`、`120min`、`2h`、`5d`，留空默认 10 分钟。保留同名投票限制。

成员在原消息上投票或改票。管理员可在原消息提前结束，或等待到期；结束后移除控件，在原频道公布结果并归档，无人投票也会公布结果。重启后恢复已有投票，并处理离线期间到期的投票。

### Market 与上架提醒

管理员在「市场队列」配置队列频道，在「上架提醒」配置通知频道。新增关注流程为：提交关键词 → 翻页选物品 → 选强化等级或不限 → 确认。每人最多 15 条关注；移除入口只列出自己的记录，打开列表不会删除内容。

任何成员可在服务器任意频道执行 `/refresh`，单次刷新到已配置的队列频道，不重置自动刷新时间。每服务器冷却 10 秒，同时进行的刷新会合并。

停止追踪会暂停该服务器的新市场请求、队列更新和上架提醒；已经发出的请求可能完成。频道配置和关注记录保留，已有队列消息标记为停止/旧数据。停止状态跨重启保留；此时 `/refresh` 仅私密提示，不请求数据，修改频道也不会自动恢复。管理员恢复追踪时验证保存的频道、立即刷新一次并恢复自动工作。初次配置通知频道仍可启用追踪。

## Slash 命令

用户本地测试并确认后，注册与运行时统一只启用以下四个入口：

| 命令 | 用途 |
| --- | --- |
| `/control set-channel` | 管理员设置中控台 |
| `/manual` | 操作手册 |
| `/ping` | 检查响应 |
| `/refresh` | 单次刷新市场 |

旧公告、报名、投票、市场及 Reminder slash 入口不再注册。相关模块仍供面板、已有消息控件和调度器调用，不删除运行数据。部署与运行时共用 `helper/slashCommands.js` 清单，保留旧模块文件不会重新注册旧命令。

## 本地运行与验收

安装依赖并运行自动检查：

```powershell
npm ci
npm test
```

本地 `.env` 使用 `CLIENT_ID`、`GUILD_ID`，以及 `DISCORD_TOKEN_DEV` / `DISCORD_TOKEN_PROD`。`ENVIRONMENT=development` 选择开发 token，其他值选择生产 token。测试时请确保应用 ID、服务器 ID 与开发 bot 匹配，不要提交 token。

以下命令由你准备好测试环境后执行：

```powershell
node deploy-commands.js
node index.js
```

注册脚本将上述四个命令同步到指定服务器，替换该应用在目标服务器的命令列表，并回读核对结果。不会修改其他服务器或全局注册。启动机器人会恢复已配置看板及调度任务。若复制现有运行数据进行测试，先备份 `storage/`。

按顺序完成 [本地验收清单](docs/control-panel-testing.md)，覆盖双账号权限、各模块、异常与重启恢复。完整设计及各模块详细验收项见 [中控台设计](docs/control-panel-design.md)。自动测试不替代 Discord 客户端上传、实际频道权限和市场 API 的联调验证。

## 数据存储

`storage/` 保存中控台及提醒配置、报名与分队、投票及归档、市场追踪状态、关注记录、公告历史、模板与角色别名，以及图片和缓存。备份时应包含 JSON 数据与对应图片文件。未完成的私密流程只在内存中保存，重启后失效。
